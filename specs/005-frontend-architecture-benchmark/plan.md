# Implementation Plan: Frontend World-Class Architecture Benchmark & Modernization

**Branch**: `005-frontend-architecture-benchmark` | **Date**: 2026-09-12 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/005-frontend-architecture-benchmark/spec.md`

---

## Summary

This plan modernizes the CropVision frontend architecture by transitioning from an untyped, monolithic Universal React Native setup with 3 fragmented map engines toward a **Clean Hybrid Architecture with GIS SPI (`contracts/IGISAdapter`)**, Web Worker spatial offloading, strict TypeScript definitions, decomposition of 24 oversized files ($> 300$ LOC) down to $\le 300$ LOC, and extensive inversion testing to elevate test coverage from 3.18% toward $\ge 90\%$.

---

## Technical Context

**Language/Version**: JavaScript (ES2023) / TypeScript 5.3+ (Strict Mode)  
**Primary Dependencies**: React 19.2.0, React Native 0.83.6, Expo SDK 55, Expo Router v3, Zustand 5, MapLibre GL 4.7.1, React Native Reanimated 4.2.1  
**Storage**: `@react-native-async-storage/async-storage` for client offline mutation persistence; REST/JSON endpoints for backend communication  
**Testing**: Jest 29, `jest-expo/node`, `@testing-library/react-native`, Playwright E2E  
**Target Platform**: Android, iOS, Desktop Web (Chrome/Safari/Firefox/Edge), Windows Desktop (Electron)  
**Project Type**: Multi-platform Mobile Field App & Desktop Web GIS Workstation  
**Performance Goals**: $\ge 55\text{ FPS}$ sustained GIS rendering with 5,000 polygons; sub-100ms UI interaction latency; $< 2.0\text{s}$ Web TTI  
**Constraints**: Zero UI thread blocking during spatial parsing; 100% offline-capable field scouting; $\le 300$ LOC per file; $\ge 90\%$ test coverage on core stores  
**Scale/Scope**: 88 source files in `App/src`, ~32,000 LOC, 24 files $> 300$ LOC targeted for modular decomposition

## Complexity Tracking

| Violation / Overhead | Why Needed | Simpler Alternative Rejected Because |
| :--- | :--- | :--- |
| **GIS SPI Abstraction (`IGISAdapter`)** | Eliminates dual-engine fragmentation between MapLibre and Native Maps | Direct imports cause coupling, duplicate coordinate transformation code, and WebGL memory leaks |
| **Web Worker Spatial Offloader** | Prevents UI thread freezes during 5,000+ polygon rendering | Main-thread computation causes dropped frames during user pinch/zoom gestures |
| **Decomposing 24 files into hooks + subcomponents** | Enforces single responsibility and Rule 2.1 ($\le 300$ LOC) | Retaining 1,000-line monolithic files makes unit testing impossible and causes regressions |
