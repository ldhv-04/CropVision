# Target Architecture Contract

Status: pending executable contract in L2.

The immutable target is a single frontend with thin `App/app/**` adapters, Station and
Agrivision owner modules with small public entries, neutral `@core`/platform services,
directed session-to-transport composition, and fixed no-growth compatibility edges.

L2 will replace this placeholder with the audited import matrix, public-entry convention,
temporary compatibility allowlist, parser coverage, and removal criteria. Until then, the
L1 source map in `00-baseline-audit.md` is descriptive evidence, not permission for a new
dependency edge.
